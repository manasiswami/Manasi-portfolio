## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/manasiswami/Manasi-portfolio.git
cd Manasi-portfolio
```

### 2. Install Frontend Dependencies

The React frontend is located in the root directory.

```bash
npm install
```

### 3. Install Backend Dependencies

Open a new terminal:

```bash
cd server
npm install
```

### 4. Configure Environment Variables

If the backend requires environment variables, create a `.env` file inside the `server` directory and add the required configuration.

Keep sensitive credentials private and never commit your actual `.env` file.

### 5. Run the Application

Start the backend using the development script configured in `server/package.json`.

Start the frontend from the root directory using its configured development script.

```bash
npm run dev
```

Open the local URL displayed in your terminal.
